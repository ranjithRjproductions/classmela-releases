# ClassMela app downloads

Vanakkam and welcome! This is the official download page for the ClassMela Android app.

## What is ClassMela?

ClassMela is an Android app for live online classes. Trainers offer courses on many subjects, and learners can browse courses, book a seat, pay in the app, and attend every class live with the trainer.

## What you are downloading

You are about to download the ClassMela Android app as an APK file, version 0.2.0 (build 2). This is a preview release shared directly by the developer - it is not from the Play Store yet. The app is free to download.

## What's new in version 0.2.0

- Updates are built in: open Settings and tap "Check for updates" to find and install new versions from inside the app.
- You can share a course with friends, and the link brings them straight to this download page.

## How to install

1. Download the app using the download link at the bottom of this page.
2. Open the downloaded file. If Android asks, allow installs from this source - this is needed only once.
3. Open ClassMela, sign up, and book your first course!
